## Food Price Trends and Household Impact Analysis


### 1. Project Description

This project analyzes how food prices have changed over time and how these changes affect affordability for households. It examines trends in essential food items including beans, maize, rice, sugar, wheat flour and meat. The goal is to provide clear insights into price patterns and identify periods where food becomes less affordable. It combines data cleaning, analysis and visualization using Microsoft Excel and Tableau to present findings in a simple and interactive dashboard.




### 2. Problem Statement


Many households struggle to manage food expenses due to rising prices. However there is often no clear understanding of how prices change over time or which food items are most affected. This project aims to solve that problem by analyzing historical food price data to identify trends highlight periods of high inflation and support better decision making for both individuals and policymakers.




### 3. Proposed Features

i) Data Integration — Import and clean food price datasets selecting only relevant columns and standardizing units for analysis.

ii) Trend Analysis — Analyze how prices of key food items change over time using PivotTables line charts and interactive Tableau dashboards.

iii) Inflation Insights — Calculate percentage changes from baseline prices to identify which commodities have increased or decreased the most.

iv) Comparative Analysis — Compare prices across different food items and regions to identify which commodities and areas are most affected.

v) Dashboard — Visualize trends averages and key insights using an interactive Tableau dashboard with filters for commodity year and region.


### 4. Tools and Concepts


i) Microsoft Excel

- Power Query for data cleaning column selection and filtering

- PivotTables for summarizing and aggregating data

- Calculations including averages percentage change and baseline comparisons

- Data formatting validation and unit conversion from per tonne to per kg

- Summary tables for price change analysis

ii) Tableau

- Interactive line charts for price trends over time

- Bar charts for percentage change comparison

- Regional price comparison charts

- Seasonal price pattern analysis

- Dashboard design with filters for commodity year and region




### 5. Data Sources


WFP Food Prices Dataset — Kenya retail food price data covering 12 commodities across 5 regions from 2007 to 2025. Source: World Food Programme via HDX (Humanitarian Data Exchange). Data collected from retail markets across Coast, Eastern, Nairobi, North Eastern and Rift Valley regions.



### 6. Expected Insights


i) Which food items have increased in price the most?

ii) When do price spikes occur?

iii) Are some food items more stable than others?

iv) How do price changes affect affordability over time?
